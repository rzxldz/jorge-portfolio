# Jorge Roldán — Portfolio

Portfolio personal desarrollado para presentar mis proyectos, habilidades, formación y perfil profesional.

## Demo

[Ver portfolio](https://jorge-portfolio-mu.vercel.app/)

## Sobre el proyecto

Este sitio funciona como mi carta de presentación profesional como estudiante de Ingeniería en Tecnologías de Cómputo y Telecomunicaciones en la Universidad Iberoamericana Ciudad de México.

El portfolio incluye:

- Información sobre mi perfil y formación
- Proyectos desarrollados
- Casos de estudio interactivos
- Carruseles de proyectos
- Habilidades técnicas
- Trayectoria académica
- Modo claro y oscuro
- Diseño responsive
- Información de contacto
