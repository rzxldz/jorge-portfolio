# Portfolio de Jorge Emmanuel Roldán Márquez

Portfolio personal construido con Next.js, TypeScript y CSS.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Después abre:

http://localhost:3000

## Antes de publicar

1. Reemplaza los enlaces `#` de LinkedIn y de los proyectos en `app/page.tsx`.
2. Coloca tu CV dentro de `public/cv.pdf`.
3. Verifica el email de contacto.
4. Sube el proyecto a GitHub.
5. Importa el repositorio en Vercel.

## Archivos principales

- `app/page.tsx`: contenido del portfolio.
- `app/globals.css`: diseño visual y responsive.
- `components/ThemeToggle.tsx`: modo claro/oscuro.
